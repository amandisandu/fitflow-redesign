# FitFlow Redesign

FitFlow is a fitness application redesign project developed as part of
IT3060 – Human Computer Interaction, Semester 2 – 2026.

## Project Objective

The objective of this project is to evaluate and select a suitable
technology stack and design a high-level system architecture for a
secure, scalable, and cross-platform fitness application.

## Recommended Technology Stack

- Frontend: Flutter
- Backend: Python / FastAPI
- Database: PostgreSQL
- Authentication: Firebase Authentication
- AI/ML: Python-based AI Microservice
- Caching: Redis
- Real-Time Layer: WebSockets / Firebase

## Key Features

- Personalized Workout Plans
- Nutrition Tracking
- Progress Tracking
- Social Features
- User Profile Management
- AI-based Recommendations
- Real-Time Notifications

## Selected Architecture

The proposed architecture uses Flutter for cross-platform frontend
development, FastAPI for backend services, PostgreSQL for structured
application data, Firebase Authentication for user authentication,
Redis for caching, and a Python-based AI microservice for personalized
fitness recommendations.
